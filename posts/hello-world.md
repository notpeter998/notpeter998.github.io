## 為什麼選擇 Docsify？

在評估多種靜態網站產生器（如 Hugo、Astro、Hexo）後，我選擇了 Docsify 作為起點，主要有以下優點：

1. **不需要 Node.js 或複雜建置工具**：
   沒有任何 `npm run build`，不需要繁複的套件依賴。
2. **純 Markdown 驅動**：
   撰寫的文章就是純粹的 `.md` 檔案，非常適合存放在 GitHub 上版本控制。
3. **極度快速的開發體驗**：
   改動檔案後重新整理瀏覽器就能立刻看到成果。
4. **原生支援 GitHub Pages**：
   將程式碼推送到 GitHub 後，免費的 GitHub Pages 就能直接將這個資料夾轉變為全球可存取的個人網站！
