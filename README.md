# 歡迎光臨 notpeter998 的個人網誌

這裡是 **notpeter998** 的個人空間！本站採用極簡現代的 **Docsify** 架構，支援純 Markdown 寫作與即時渲染，並可直接託管在 GitHub Pages 上。

---

## 🌟 特色與亮點

- **純 Markdown 撰寫**：無需複雜的編譯步驟，寫完 Markdown 立即預覽。
- **內建全文搜尋**：右上角或側邊欄提供即時搜尋功能，快速索引文章內容。
- **響應式排版**：完美支援手機、平板與桌面電腦閱讀。
- **程式碼語法高亮**：支援各類主流程式語言高亮與一鍵複製。

## 📝 如何新增一篇文章？

只要兩個步驟：
1. 在 `posts/` 資料夾下新增一個 `.md` 檔案（例如 `posts/my-new-post.md`）。
2. 在 `_sidebar.md` 加上文章連結：
   ```markdown
   * [我的新文章標題](posts/my-new-post.md)
   ```
3. 提交並推送到 GitHub，GitHub Pages 就會自動更新！
